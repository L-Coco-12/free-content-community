WebP fixtures are generated test patterns (4 by 4 pixels), created locally with FFmpeg's libwebp encoder.
No third-party photographs or artwork are included.

- lossy.webp: red, lossy, one frame.
- lossless-alpha.webp: blue with alpha, lossless, one frame.
- animated.webp: testsrc, two frames at 2 fps, looping.

PNG/JPEG/GIF fixtures are generated with JDK ImageIO inside the tests.
